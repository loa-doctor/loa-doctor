# 🩺 LOA Doctor

**LOA Doctor**는  
로스트아크 플레이 중 **실시간 화면 공유를 기반으로 보스 UI를 분석**하고,  
현재 상황에 맞는 **공략 정보를 Picture-in-Picture(PiP)** 형태로 제공하는 웹 서비스입니다.

로아를 하는데 있어서 가장 큰 장벽인 트라이의 두려움을 줄이고자 도움을 받을 수 있는 사이트를 개발하기로 하였습니다.

---

## 🎯 프로젝트 목표

- 로스트아크 보스전 중 **실시간 화면 트래킹**
- 보스 체력, 패턴 구간 등 **시각 정보 자동 인식**
- 상황에 맞는 **공략 가이드 즉시 제공**
- 게임 플레이 흐름을 방해하지 않는 **PiP UI 제공**

---

## 🧠 핵심 아이디어

1. **WebRTC 화면 공유**
   - 사용자가 브라우저를 통해 게임 화면을 공유
2. **실시간 화면 분석**
   - OpenCV 기반으로 보스 HP 바, 패턴 전환 시점 등을 인식
3. **공략 매칭**
   - 현재 보스 상태에 맞는 공략 데이터 매칭
4. **Picture-in-Picture 출력**
   - 영상 위가 아닌, OS 레벨 PiP로 공략 정보 표시

---

## 🛠 기술 스택

### Frontend
- **Next.js**
- **TypeScript**
- **Tailwind CSS**
- WebRTC (getDisplayMedia, RTCPeerConnection)
- Picture-in-Picture API

### Backend
- **Node.js (Express)**
- WebRTC Signaling
- OpenCV (영상 프레임 분석)
- (Optional) Worker / Queue 구조

### Database
- **MongoDB** (예정)
  - 보스 정보
  - 패턴 타이밍
  - 공략 데이터

## ⚠️ 참고 사항

- 본 프로젝트는 **개인 학습 및 기술 실험 목적**으로 진행됩니다.
